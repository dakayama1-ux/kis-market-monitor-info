개인정보처리방침

목적과 정보

본인의 시장·계좌 기록을 저장·확인하기 위해 CSV 내용, 접근이 허용된 Drive 파일의 이름·식별자, OAuth 인증 정보를 처리합니다. 로컬에는 실행 로그도 생성됩니다.

보관과 삭제

CSV는 Windows 컴퓨터와 연결된 Google Drive에 저장되고, OAuth 인증 정보는 로컬 rclone 설정 파일에 저장됩니다. 날짜별 기록은 누적되고 최신본은 덮어씁니다. 점검한 코드에는 기간에 따른 원본 CSV·로그 자동 삭제 기능이 없습니다. 사용자가 기록을 직접 관리·삭제하며, 업로드용 임시 파일 삭제는 원본 삭제와 다릅니다.

이용 종료

자동 업로드를 중지하고 Google 연결을 해제한 뒤 로컬 파일·인증 정보·Drive 파일·별도 백업을 각각 정리해야 합니다. 연결 해제만으로 저장된 파일이 삭제되지는 않습니다. 연결은 Google 계정 관리에서 해제할 수 있습니다.

전송

점검한 업로더는 CSV를 Google Drive에 복사합니다. 해당 코드에서는 로그 자동 업로드나 다른 분석 서비스로의 직접 전송이 확인되지 않았습니다. 사용자가 별도로 연결한 열람·분석 서비스는 이 업로더와 구분되며, 각 서비스의 권한·처리 조건을 확인해야 합니다.

운영 방침

이 앱을 통해 처리하는 Google 사용자 데이터는 기록 저장·갱신·확인 목적으로 사용하며, 판매·광고·범용 AI 모델 학습 목적으로 사용하거나 제공하지 않습니다. Google API에서 받은 정보의 사용·전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

안내 페이지

입력 폼·광고·분석 스크립트를 넣지 않습니다. 호스팅 제공자의 자체 정보 처리는 해당 서비스 정책을 따릅니다. 처리 방식이 변경되면 방침도 수정합니다.
